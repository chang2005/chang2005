SerialScope

C++ Qt 6 / C++17

“The only serial tool you’ll ever need — a fast, protocol-aware UART/serial debugger for Windows, macOS & Linux.” 跨平台串口调试与数据可视化工具，Windows 优先开发，Linux / macOS 保持可编译。

★ 0 fork 0 GPL-3.0 最近推送 2026-11-17 版本 V1.0 主题标签：未设置
  • 串口配置：自动枚举 + 手动输入端口（COM3、/dev/ttyUSB0）、热插拔刷新保留当前选择；波特率 300–4,000,000 预设加 50–20,000,000 自定义；数据位/校验位/停止位/流控齐全；打开串口期间锁定参数栏。
  • 收发与校验：ASCII / HEX 双视图，UTF-8 / GBK / ASCII 编码；HEX 输入容错空格、逗号与 0x 前缀；可附加 CRC16-Modbus / CRC16-CCITT / Sum8；定时发送、最近 50 条历史、分块文件发送与取消。
  • 多通道波形：数据源可为 ASCII 行内数值（自动映射 CH1…CH8）或二进制 HEX 帧字段（自定义帧头/固定帧长/长度字节模式，字段表支持 int8…float32 与大小端）；5–30–60 秒滚动窗口、CSV 导出、按像素列 min/max 包络降采样。
  • 工程化：异步有界队列日志（溢出插缺口标记）、CRC 工具箱、暗色/亮色主题、配置持久化；ctest 两组测试（核心库 + 串口配置 UI）；Windows 发布包含 Qt 运行库与 SHA256SUMS.txt。

IC-Inventory

JavaScript Vue 3 · Node.js · MySQL

面向电子制造企业的「器件档案 · 库存 · BOM 缺料分析 · 采购闭环 · 出入库」一体化管理系统，贯通 BOM 上传 → 缺料计算 → 采购申请 → 下单收货 → 入库出库 → 报表分析的完整链路。

★ 0 fork 0 MIT 最近推送 2026-10-30 主题标签：未设置
  • 技术栈：前端 Vue 3 + Element Plus + ECharts + SheetJS（免构建，依赖内置于 web/vendor）；后端 Node.js 18+ / Express 5 / mysql2；数据库 MySQL 8.0（InnoDB / utf8mb4）；认证 JWT + bcrypt；前后端同源部署，单进程即可运行。
  • BOM 智能导入：自动定位表头行、中英文列名匹配、无表头文件兜底；按「料号 → 品牌+型号 → 型号 → 名称+封装」逐级匹配，输出精确/型号/疑似/未匹配统计，未匹配可一键建档回填。
  • 缺料计算规则：需求量 = ceil(单台用量 × 计划数量 × (1+损耗率%))；可用量 = 现有 − 已预留 + 在途；缺口按替代料可用量合并抵扣。
  • 库存一致性：出库「提交预占 + 确认扣减」两步式，确认时 SELECT ... FOR UPDATE 行锁防并发超发；入库按移动加权均价更新；所有变动写入 stock_transaction。
  • 权限与运维：三级角色（超级管理员/管理员/员工）权限矩阵、操作日志、Excel 智能入库导入、一键备份脚本、PM2 + Nginx 部署说明。

loves_me_not

Python 零第三方依赖

“loves-me-not —— 撕开聊天记录的花瓣，看看 TA 爱不爱你 🌼”把导出的聊天记录在本机算成 0–100 的情感投入指数，生成可直接分享的单文件 HTML 报告。

★ 0 fork 0 MIT（README 标注） 最近推送 2026-10-06 主题标签：未设置
  • 输入兼容：.txt .log .csv .json .html 容错解析，自动识别说话人与时间戳；自动探测 UTF-8 / GB18030 / Big5 / UTF-16 编码；HTML 需先从页面内嵌数据中抠出消息再解析。
  • 量化与描述：五个量化指标（回复速度、每 5 分钟消息数、深夜消息数、打破僵局次数、最后发言次数）+ 八个描述性维度，每项都标注计算口径与数据来源。
  • 可解释打分：八维模型 60% + 五个量化指标 40%，再按样本量向 50 收缩；三条硬规则——「没有信息 ≠ 0 分」「样本不足要收窄结论」「绝不虚构」。
  • 报告：14 页单文件 HTML（雷达、趋势、日历热力图、词云、行为画像、时间线、原话证据链、权重分账），零外部请求；--redact 可打码手机号、身份证、卡号、邮箱等。
  • 工程约定：245 项单元测试，其中一批是守住「全本地、样本不足不下结论、不虚构」等承诺的护栏；包内禁止任何网络依赖。

bcm6135-arduino-pmbus

C++ Arduino · PMBus

针对 Vicor BCM6135CD1E5165yzz DC-DC 转换器的 Arduino PMBus/I2C 测试程序：地址探测、EN 控制、遥测/状态/能量读取、轮询与 Serial Plotter 支持。

★ 0 fork 0 MIT 最近推送 2026-08-28 主题标签：未设置
  • 流程：Wire 以 100 kHz 初始化 → 探测默认地址 0x5F，未找到则扫描 0x08–0x77 → 等待 5 秒后拉低 EN 使能功率级 → 读取遥测与状态寄存器。
  • 串口命令：h 帮助、s 扫描总线、A 5F 设地址、i 读身份、r 单次遥测、p 每 2 秒轮询、t 状态寄存器、e 能量累加器、c CLEAR_FAULTS、o/f OPERATION 开关。
  • 寄存器：OPERATION 0x01、CLEAR_FAULTS 0x03、READ_EOUT 0x87、READ_VIN 0x88、READ_VOUT 0x8B、READ_IOUT 0x8C、READ_TEMPERATURE_1 0x8D、READ_POUT 0x96、READ_K_FACTOR 0xD1、STATUS_BYTE/WORD 0x78/0x79。
  • 仓库内含 BCM 官方数据手册 PDF 与中英双语 README；ADDR 引脚 16 档外部电阻取值与 7 位地址的对照表一并列出；程序对 AVR 板卡做了 SRAM 优化（固定字符串入 Flash）。
