SerialScope

C++ Qt 6 ★ 0

跨平台、协议感知的 UART/串口调试器，Windows 优先，Linux 与 macOS 可编译。

  • 收发：ASCII / HEX 双视图，UTF-8 · GBK · ASCII，可附 CRC16-Modbus / CRC16-CCITT / Sum8
  • 波形：ASCII 行内数值或二进制帧字段（int8…float32，大小端），5–60 秒滚动窗口与 CSV 导出
  • 工程：异步有界队列日志、CRC 工具箱、暗/亮主题，ctest 两组测试

IC-Inventory

JavaScript Vue 3 ★ 0

面向电子制造企业的元器件供应链一体化系统，贯通 BOM 导入到出入库与报表的完整链路。

  • 缺料计算：需求量 = ceil(单台用量 × 计划数量 × (1+损耗率%))，可用量 = 现有 − 已预留 + 在途
  • 一致性：出库「提交预占 + 确认扣减」，确认时 SELECT … FOR UPDATE 行锁防超发
  • 栈：Vue 3 + Element Plus + ECharts（免构建）/ Node.js 18+ / Express 5 / MySQL 8.0

loves_me_not

Python 零第三方依赖 ★ 0

把导出的聊天记录在本机算成 0–100 的情感投入指数，生成可直接分享的单文件 HTML 报告。

  • 兼容：.txt / .log / .csv / .json / .html 容错解析，自动探测 UTF-8 / GB18030 / Big5 / UTF-16
  • 打分：八维模型 60% + 五个量化指标 40%，按样本量向 50 收缩，不足即不下结论
  • 报告：14 页单文件 HTML（雷达 / 热力图 / 词云 / 原话证据链），--redact 打码，245 项单元测试
